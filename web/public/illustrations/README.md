# Aruzahr görsel varlıkları

8 Ekim 2026. On bir şehir sahnesi, üç doğa/deniz sahnesi ve dört portre, kullanıcının görsel üretim isteğiyle oluşturulmuş fantastik illüstrasyonlardır. Nüfus ve harita ölçümü belgesi değildir.

`ashara.webp`, kullanıcı tarafından GitHub’a yüklenen özgün `Ashara.png` dosyasının web için küçültülmüş kopyasıdır; özgün dosya korunur. Portre adı dışında karakterin gizli kimliği veya görev bilgisi bu varlığa eklenmez.

Şehir sahneleri: Valdareth, Dorvenhall, Marhalden, Frostbay, Ternhaven, Dranthol, Vyssgard, Kaldmere, Lirendil, Theramis, Elorwyn. Doğa sahneleri: Karlan, Frostmere, Ak Cam. Portreler: Eryndorn, Nera Veld, Edran Korr, Bryndon. Toplam 18 yeni illüstrasyon ve Ashara kopyası; dış görsel sunucusu gerekmez.
