Yeni ülke/şehir belgesini `bolgeler/`, karakter görselini `karakterler/`, macera taslağını `maceralar/` içine ekle. Hazır site görsellerinin ve karakterlerinin otomatik güncellenmesi için ayrıca uygulama verilerine işlenmeleri gerekir.

Yazarın geliştirilmiş evren metinleri [lore/](../lore/README.md), uygulamanın yayın görselleri `web/public/illustrations/` içindedir. Kaynak dosyaları web uygulamasının herkese sunduğu `public/` klasörüne taşınmadı.
