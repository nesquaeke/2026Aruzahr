# Siteyi başlat

Deponun **tamamını** indirip ZIP'ten çıkar. Bu klasörü tek başına indirmek yeterli değildir; yanındaki `web/` ve `kaynaklar/` klasörleri gerekir. [Node.js LTS](https://nodejs.org/en/download) 22.12 veya üzerini kur.

| Amaç | Windows | macOS / Linux |
|---|---|---|
| Atlas ve wiki | [BASLAT.bat](BASLAT.bat) | `bash baslat/baslat.sh` |
| Hikâye ve yayın masası | [Yayini-Baslat.cmd](Yayini-Baslat.cmd) | `bash baslat/Yayini-Baslat.sh` |
| Aynı ağdan telefon kumandası | [Yayini-Uzaktan-Baslat.cmd](Yayini-Uzaktan-Baslat.cmd) | `bash baslat/Yayini-Uzaktan-Baslat.sh` |

Windows'ta dosyayı çift tıkla. Bash komutları depo ana klasöründen çalıştırılır; dosyanın tam yolunu kullanarak başka klasörden de çalıştırabilirsin. macOS'ta [BASLAT.command](BASLAT.command), atlas başlatıcısının çift tıklanabilir karşılığıdır.

İlk açılışta bağımlılıklar ve harita katmanları hazırlanır. Terminali açık tut; kapatmak için **Ctrl+C** kullan. Yayın Masası açıldıktan sonra hazır hikâye otomatik gelir; ayrıca DM dosyası yüklemek gerekmez.
