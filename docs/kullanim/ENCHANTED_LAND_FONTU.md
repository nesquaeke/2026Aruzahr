# Enchanted Land · karakter ve OBS isimleri

Kullanıcı tarafından 29 Ekim 2026'da sağlanan font: **Enchanted Land Regular**, Dennis Ludlow / Sharkshock.

## OBS / Windows

1. [Özgün font ZIP'ini](../../kaynaklar/fontlar/enchanted_land.zip) indir ve **Tümünü ayıkla** de.
2. `Enchanted Land.otf` dosyasına sağ tık → **Tüm kullanıcılar için yükle**; bu seçenek yoksa **Yükle**.
3. OBS'yi tamamen kapatıp yeniden aç.
4. İsim metninin Özellikler → Yazı tipi bölümünden **Enchanted Land**, stil **Regular** seç.
5. 1920×1080 yayın için görünen isimde yaklaşık 28–36 px ile başla. Açık krem renk, 1–2 px koyu anahat kullanılabilir. Metin kaynağını çok küçük çizip sonradan büyütmek yerine yazı tipi boyutunu artır; kamera grubunu orantılı küçült.

Site fontu kendi dosyasından yükler; ziyaretçilerin Windows'a ayrıca yüklemesi gerekmez. OBS'deki bağımsız Metin (GDI+) kaynağı ise fontun o bilgisayarda yüklü olmasını gerektirir. Sitenin Tarayıcı Kaynağı portre isimleri otomatik yeni fontu kullanır.

## Sitedeki kullanım

Karakter kartları ve büyütülen portre isimleri, karakter wiki başlığı, yayındaki portre isimliği, Oyuncu Masası'nda kayıtlı karakter adı ve yeni yazdırılan A4'ün karakter adı. Uzun anlatılar ve kontrol düğmeleri mevcut gövde fontunu kullanır. Eski raster görsellerin içine gömülmüş yazılar bu değişiklikle yeniden çizilmez. Önceden indirilmiş PDF/video gibi sabit dosyalar değişmez; yeni karakter çıktıları güncel fontla oluşturulur.

Font değiştirilmeden gömülür; Türkçe `ç Ç ğ Ğ ı İ ö Ö ş Ş ü Ü` glifleri dosyada mevcuttur. Orijinal ZIP `kaynaklar/fontlar/`, kullanılan OTF ve değiştirilmemiş readme `web/public/fonts/EnchantedLand/` içindedir.
